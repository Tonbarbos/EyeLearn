# EyeLearn
EyeLearn é um aplicativo que fornecerá um ambiente de aprendizado para crianças de 7 a 10 anos de idade, contando com o apoio de inteligências artificiais e ferramentas como o rastreamento ocular (Eye Tracker, em inglês) para detectar possíveis padrões de defict de atenção, a fim de auxiliar no aprendizado do aluno.
